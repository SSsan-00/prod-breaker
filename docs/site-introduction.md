# PROD BREAKER — 本番環境は壊れる。でもコンボは止まらない。

**BUILD THE BUG. BREAK THE PROD.**

暴走するバグを操作して、架空のデータセンターを連鎖爆破。次々と押し寄せる復旧部隊をかわしながら、障害を広げて生き延びるブラウザゲームです。

**[PROD BREAKERをプレイする](https://prod-breaker.vercel.app/)**

![PROD BREAKERのプレイ画面](game.png)

## 逃げて、育てて、連鎖させる

操作するのは移動だけ。攻撃は自動で発射され、サーバーや敵を破壊すると周囲へ障害が伝播します。障害ログを集めてレベルアップし、3つの候補から強化を選びましょう。選択中はゲームが一時停止します。

無限リトライ、WHERE句行方不明、金曜17:59……。開発・運用・セキュリティの「あるある」を題材にした強化を組み合わせると、思いがけない**進化**が発動します。たとえば「無限リトライ」と「タイムアウト延長」で、連鎖を強める「リトライストーム」に。どんな構成を作るかはあなた次第です。

ピンチには **PANIC**。周囲にダメージを与え、障害ログを回収し、短時間無敵になります。連鎖を重ねると **OVERDRIVE** が発動し、10秒間攻撃が加速。次々と爆発をつないで、ハイスコアを狙いましょう。

## 好きな時間だけ、本番を壊す

| モード | 生存時間の目標 | おすすめ |
| --- | --- | --- |
| QUICK | 90秒 | まずは気軽に1プレイ |
| STANDARD | 3分 | 強化の組み合わせを楽しむ |
| CHAOS | 5分 | じっくり連鎖を育てる |
| ENDLESS | 30分から先へ | 長期戦と高スコアに挑戦 |

WAVEは30秒ごとに進み、強力なSRE COREが増援として登場します。ENDLESSで30分生き延びると、さらに5分間の裏モードへ。強化されたSRE COREとの戦いが続き、獲得BPは2倍になります。

## 操作方法

- **スマホ：** プレイ画面をドラッグして移動。
- **PC：** WASDまたは矢印キーで移動。SpaceキーでPANICを発動。
- **一時停止：** 画面上部の一時停止ボタン、またはPCのEscキー。

設定から音量や演出軽減を調整できます。初期状態では音声がミュートされています。

## 障害の結末を、みんなと共有

プレイ終了後は、獲得BPや最大連鎖、称号とともに、ジョークの障害報告書が表示されます。スコアはプレイヤー名とともに自動登録され、モード別のスコアボードで確認できます。名前は変更可能で、初回はユーモアのある名前がランダムに付与されます。

気に入った構成をもう一度試すのも、新しい進化を探すのも自由。リザルトからすぐに再挑戦できます。
